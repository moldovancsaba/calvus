# Lexodont — token map

*Written 2026-09-18. Short, because there is nothing to map.*

The wireframe's tokens (`05-design.md` §Tokens) are a deliberate grey-scale with no
radius and no shadow — a wireframe idiom, not a design system. The live site was built
on Bootstrap 5 with the Outfit typeface, its own palette and Bootstrap Icons. No token
of the wireframe corresponds to a production value, and inventing a table would imply a
hand-off that never happened.

What did carry over is structural, not tokenised: section order, page set, navigation,
the contact block, the before/after component, the two-column featured specialties.
Those are recorded in `02-audit.md` and `10-ssot.md`.

If the wireframe were ever used to specify a redesign, the mapping would be written
then, against the theme's actual `style.css` (162 KB, measured) — not now.
